# Security Policy

## Reporting a Vulnerability

Als je een veiligheidslek vindt, maak dan geen public issue aan.
Contacteer de onderhouder rechtstreeks met details over het lek.

## Scope

Dit project bevat Pwnagotchi plugins voor text-to-speech en voice assistant functionaliteit.
Veiligheidsproblemen die leiden tot remote code execution of ongeautoriseerde toegang zijn in scope.

## Disclaimer

Dit project is bedoeld voor legitieme security research en educatieve doeleinden.
