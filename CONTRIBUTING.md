# Contributing to pwnspeaker

Bedankt voor je interesse om bij te dragen aan pwnspeaker!

## Hoe bij te dragen

1. **Fork** de repository
2. **Creëer** een nieuwe branch (`git checkout -b feature/my-feature`)
3. **Voeg** je wijzigingen toe
4. **Test** je wijzigingen lokaal
5. **Commit** met duidelijke commit messages
6. **Push** naar je fork
7. **Open** een Pull Request

## Code-stijl

- Volg PEP 8 voor Python-code
- Gebruik duidelijke variabelenamen
- Voeg comments toe waar nodig

## Licentie
